==================================

If you are reading this...

Congratulations.

You were curious enough to find this file.

But there is something you should know.

You did not intentionally download this file.

You clicked a button that said:

```
                "CONTINUE"
```

You thought that button was simply going to take
you to the EOC Youth Gospel of John study.

And it did.

But it ALSO downloaded this file.

---

```
                NOTHING WAS STOLEN
```

This file is completely harmless.

No password was collected.
No account was accessed.
No malware was installed.
No damage was done to your device.

This was a controlled cybersecurity awareness exercise.

---

```
                SO WHAT HAPPENED?
```

You trusted the website because it looked familiar.

You trusted the button because it looked harmless.

You expected the button to do one thing:

```
                "Continue to the study."
```

You didn't know it was doing something else.

And that is the lesson.

A real attacker doesn't necessarily need you to
download something that looks dangerous.

They can hide something unexpected behind something
you already trust.

---

```
             JUDAS SCAMARIOT
```

The person who created this simulation was not some
random hacker on the internet.

It was "Judas Scamariot."

He used something you already trusted:

```
                EOC YOUTH
```

He gave you something you wanted:

```
                THE JOHN STUDY
```

And he hid something you weren't expecting:

```
                THIS FILE
```

That is social engineering.

---

```
              ASK YOURSELF:
```

Did you read the URL before clicking?

Did you know exactly where the button would take you?

Did you expect a file to download?

Did you check what had actually happened afterwards?

Would you notice if the downloaded file had been
something more dangerous?

---

```
                 REMEMBER

             STOP.
             THINK.
             VERIFY.
```

A familiar name does not make a link safe.

A familiar website does not make a download safe.

A trusted person can have their account compromised.

And a button can do more than you expect.
